# วิธีเติมข้อมูลเพื่อน

แก้ไฟล์เดียวคือ `friends.json` แล้วรัน `npm run validate` ทุกครั้งก่อน commit

```bash
npm run validate
```

## โครงของเพื่อน 1 คน

```json
{
  "id": "nut",
  "nickname": "นัท",
  "aliases": ["nut", "ไอ้นัท"],
  "photo": "friends/nut.webp",
  "attrs": { ... },
  "reveal": { ... }
}
```

| field | ต้องมี | อธิบาย |
|---|---|---|
| `id` | ✅ | ตัวพิมพ์เล็ก a-z, 0-9 และ `-` เท่านั้น **ห้ามแก้หลังปล่อยเว็บ** เพราะระบบใช้ id สุ่มข้อประจำวัน ถ้าเปลี่ยนแล้วข้อจะเลื่อนทั้งกระดาน |
| `nickname` | ✅ | ชื่อที่ต้องพิมพ์ตอนทาย ห้ามซ้ำกับคนอื่น |
| `aliases` | ✅ | ชื่อสำรองสำหรับช่องค้นหา ใส่ `[]` ได้ถ้าไม่มี |
| `photo` | ✅ | พาธใต้ `public/` เช่น `friends/nut.webp` ยังไม่มีรูปก็ใส่ชื่อไว้ก่อนได้ (จะขึ้นตัวอักษรแทน) |

## `attrs` — ช่องที่เอาไปเทียบในโหมดคลาสสิก

| key | ชนิด | ค่าที่ใส่ได้ |
|---|---|---|
| `birthYear` | ตัวเลข | ปี ค.ศ. เช่น `1995` |
| `height` | ตัวเลข | เซนติเมตร เช่น `175` — ห่างกันไม่เกิน 4 ซม. จะขึ้นเหลือง |
| `sports` | array | เลือกจาก `SPORT_OPTIONS` ใน `attributes.ts` (ใส่คำอื่นได้แต่จะขึ้นคำเตือน) ใส่ได้หลายอย่าง |
| `football` | ข้อความ | `GK` `CB` `LB` `RB` `LWB` `RWB` `CDM` `CM` `CAM` `LM` `RM` `LW` `RW` `ST` `CF` หรือ `NONE` ถ้าไม่เล่นบอล |
| `exTier` | ข้อความ | `น้อย` (ไม่เกิน 2) · `กลาง` (3–5) · `มาก` (เกิน 5) |
| `status` | ข้อความ | `โสด` · `มีแฟน` · `แต่งงานแล้ว` · `ไม่ขอออกความเห็น` |
| `vibe` | array | เลือกจาก `VIBE_OPTIONS` เช่น `สายเหล้า` `สายเกม` `สายบ้าน` |
| `job` | ข้อความ | สายงานกว้างๆ เช่น `โปรแกรมเมอร์` `เซลล์` — ใช้คำเดียวกันทั้งไฟล์ ไม่งั้นคนสายเดียวกันจะไม่ขึ้นเขียว |
| `province` | ข้อความ | ต้องตรงกับรายชื่อใน `provinces.ts` เป๊ะ เช่น `กรุงเทพฯ` (ไม่ใช่ `กรุงเทพ`) |

## `reveal` — ใช้ตอนเฉลยและเป็นโจทย์ของโหมดอื่น

| key | อธิบาย |
|---|---|
| `signature` | มุกหรือพฤติกรรมประจำตัว โผล่ตอนทายถูก — ใส่ให้ฮาได้เลย |
| `emoji` | อย่างน้อย 3 ตัว เรียงจาก**ใบ้ยากไปใบ้ง่าย** เพราะเกมเปิดทีละตัวจากซ้าย |
| `quotes` | ประโยคติดปาก อย่างน้อย 1 วลี ใส่หลายวลีได้ เกมจะสุ่มมาวันละอัน |

## เพิ่มคอลัมน์ใหม่

1. เพิ่ม 1 entry ใน `attributes.ts` (ลำดับใน array = ลำดับคอลัมน์ในตาราง)
2. เพิ่ม field นั้นใน `attrs` ของ **ทุกคน**
3. `npm run validate` จะบอกเองว่าใครยังไม่ได้เติม

## รูปเพื่อน

วางที่ `public/friends/<id>.webp` เป็นสี่เหลี่ยมจัตุรัส ~512px
โหมดรูปเบลอจะเริ่มจากเบลอหนักแล้วค่อยชัดขึ้น เลือกรูปที่เห็นหน้าชัดๆ จะสนุกกว่า
