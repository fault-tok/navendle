# navendle

เกมทายเพื่อนในกลุ่ม **NAVEN** วันละข้อ ได้ไอเดียมาจาก dragonballdle / onepiecedle
เป็นเว็บ frontend ล้วน ไม่มี backend ไม่มีฐานข้อมูล ข้อมูลเพื่อนอยู่ใน JSON ไฟล์เดียว

## เล่นยังไง

ทายว่าวันนี้เป็นเพื่อนคนไหน ทายได้ไม่จำกัดครั้ง ทุกครั้งที่ทายจะได้เบาะแสเพิ่ม

| โหมด | โจทย์ |
|---|---|
| 📋 คลาสสิก | ตารางคุณสมบัติ — เขียว = ตรง, เหลือง = ใกล้เคียง, ▲▼ = คำตอบมากกว่า/น้อยกว่า |
| 😎 อิโมจิ | อิโมจิเปิดทีละตัวทุกครั้งที่ทายผิด |
| 💬 วลีเด็ด | ประโยคติดปาก ทายผิด 2/4/6 ครั้งปลดคำใบ้ |
| 🖼️ รูปเบลอ | รูปชัดขึ้นทุกครั้งที่ทายผิด |

แต่ละโหมดเป็นคนละคนกันในวันเดียวกัน และเปลี่ยนคนใหม่เที่ยงคืนตามเวลาไทย
ความคืบหน้ากับสถิติเก็บใน localStorage ของเครื่องที่เล่น

## คำสั่ง

```bash
npm install
npm run dev        # เปิด http://localhost:5173/navendle/
npm run validate   # ตรวจ src/data/friends.json
npm test           # unit test + smoke test ของหน้าเว็บ
npm run build      # validate → typecheck → build (ข้อมูลผิดจะไม่ผ่าน)
npm run preview
```

ตอน dev ใส่ `?day=5` ท้าย URL เพื่อข้ามไปข้อที่ 6 ได้โดยไม่ต้องแก้นาฬิกาเครื่อง
และ `?m=emoji` เพื่อเปิดตรงโหมดที่ต้องการ

## เติมข้อมูลเพื่อน

ดู [`src/data/README.md`](src/data/README.md) — สรุปสั้นๆ คือก๊อป `friends.example.json`
ไปเป็น `friends.json` แล้วเติมทีละคน จากนั้นวางรูปที่ `public/friends/<id>.webp`

> ข้อมูลทุกอย่างใน `friends.json` จะเปิดอ่านได้จากเว็บที่ deploy แล้ว
> ใช้ชื่อเล่นล้วน ไม่ต้องใส่ชื่อจริง–นามสกุล–ที่ทำงานจริง และบอกเพื่อนก่อนขึ้นเว็บ

## Deploy

push เข้า `main` แล้ว GitHub Actions จะ build ขึ้น Pages ให้เอง
(ตั้งค่า repo → Settings → Pages → Source = **GitHub Actions** ครั้งเดียว)

repo ต้องชื่อ `navendle` เพราะ `base` ใน `vite.config.ts` ตั้งไว้เป็น `/navendle/`
ถ้าใช้ชื่ออื่นหรือ custom domain ให้แก้ `base` ตาม

## โครงสร้าง

```
src/data/       ข้อมูลเพื่อน + นิยามคอลัมน์ (แก้ที่นี่เวลาเพิ่มคน/เพิ่มช่อง)
src/game/       ตรรกะเกม — เทียบค่า, สุ่มข้อประจำวัน, เซฟ, ข้อความแชร์
src/composables/ state ของแต่ละโหมดและสถิติ
src/components/ UI
```
